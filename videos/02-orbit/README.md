# 02 · ORBIT

第二期成片：一段 30 秒的原创生成式动态影像《ORBIT》（96 BPM，D 小调，墨黑 + 奶油白 + 珊瑚红）。
一个光点 → 行星和三颗卫星 → 九天体星系连成星座 → 倒数加速坍缩 → 银河爆发（PULL / SPIN / BEND / BURN / FALL / IN）→ 一切回到一个光点。

- 成片：`output/orbit.mp4`（30s，1920×1080，30fps）
- 提示词：仓库根目录 `PROMPT_ORBIT.md`

## 分段（12 小节，每小节 2.5s）
| 时间 | 画面 | 声音 |
|---|---|---|
| 0–5s | 光点、每拍一圈声呐波纹、十字刻度线、标题 ORBIT 逐字出现 | 低音持续音、声呐 ping、逐字 tick |
| 5–10s | 光点长成行星，三颗卫星依次入轨并带标签 | 轻底鼓、琶音、Dm 铺底 |
| 10–15s | 镜头拉远出九天体星系，每拍连一条珊瑚红星座线，俯视角抬高 | 完整鼓组、贝斯、每条线一个上行音 |
| 15–17.5s | 4-3-2-1 倒数，轨道加速并向中心坍缩，画面抖动 | 军鼓滚奏、上升噪声、音高爬升 |
| 17.5–25s | 白闪后银河爆发，4500 颗粒子差速旋转，每半小节砸一个大字，最后被吸回中心 | 冲击、四拍底鼓、侧链和弦、每个字一记重击 |
| 25–30s | 珊瑚红冲击环，光点和波纹回归，EVERYTHING RETURNS | Dsus2 → D 解决，余音淡出 |

## 目录
| 路径 | 内容 |
|---|---|
| `film/orbit.js` | 全部动效：每一帧都是时间 t 的纯函数，Canvas 2D 绘制 |
| `film/score.py` | 配乐与音效，numpy 合成，提示点与 `orbit.js` 对齐 |
| `film/render.mjs` | Playwright 渲染：4 个页面并行，每帧 16 个子帧在页面内 GPU 平均（180° 快门运动模糊） |
| `film/index.html` | 1920×1080 画布；直接用浏览器打开可实时预览 |
| `output/` | 成片（提交） |
| `out/` | 中间文件（不提交） |

## 构建
```bash
./build.sh
```
约 3–4 分钟（4 核）。
