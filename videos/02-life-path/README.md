# 02 · 人与人的路

约 87 秒的纯文字视频。语音和逐字稿来自参考视频二，呈现方式参考视频一：一次只显示一句，每个字在被念到的那一刻波动出现。
背景是程序生成的水墨山水，跟着文案走：雾 → 黄昏 → 庐山 → 风雨 → 小船 → 群山青翠。

- 成片：`output/life_path.mp4`

## 关键句的语义动效
| 句子 | 动效 |
|---|---|
| 站在雾里 / 也很迷茫 / 不必回头看 | 起雾、字从雾中变清楚；"迷茫"一直虚焦漂浮；雾散 |
| 蔷薇今年谢了 / 明年还会再开 | 字像花瓣飘落 / "再开"旋转绽放 + 光环 |
| 勇敢点，向前走 | "向前走"一步步走出画面 |
| 即使寿弱蜉蝣 / 而有的人寿比冥灵 | 字小、闪烁、随风散开 / 字大而沉，稳稳落下 |
| 却终岁不得自由 | 一个方框把整句框住 |
| 虚度自己的光阴年华 | 每个字出现后慢慢变暗 |
| 翻然醒悟 / 辞别了人间 | "醒悟"发光 + 全屏暖光一闪 / 字化成细尘飘散 |
| 然而身在庐山之外 / 又岂能知晓山中人之想呢 | 竖排；背景一座大山升起 |
| 人与人的路是不可复制的 | 左右两层重影收拢成一份 |
| 风雨再大 / 步履维艰 / 刺得我伤痕遍布 | 斜雨 + 字轻颤 / 整句一顿一顿往前挪 / 三道划痕 |
| 我相信独游的小船 | 字在水面上浮动，带倒影；背景小船漂过 |
| 两岸群山青翠，虫鸟同鸣 | 山水转青绿，飞鸟掠过，淡出 |

## 目录
| 路径 | 内容 |
|---|---|
| `src/lines.json` | 校对后的逐字稿 + 每句的位置、字号、高亮词、动效、背景色调关键帧 |
| `tools/asr.py` / `tools/asr_raw.json` | faster-whisper 识别结果（逐字时间，已缓存） |
| `tools/align.py` | 把逐字稿对齐到语音时间，生成 `src/timeline.js` |
| `src/film.js` | 文字动效 |
| `src/bg.js` | 水墨山水背景（`?bg=paper` / `?bg=bokeh` 可切换另两种） |
| `src/render.mjs` | 逐帧渲染 |

## 构建
```bash
./build.sh <参考视频二.mp4>
```
