# 04 · 产品宣传片：免费解析去水印工具

30 秒产品宣传片（1920×1080，120 BPM）。素材是一段 45 秒的网站操作录屏，粗剪后放进干净的圆角窗口，配卡点推拉运镜、标注气泡和图文卡片。配色沿用网站本身：淡紫渐变、主紫 `#5B3DF5`、墨黑、白。

- 成片：`output/promo.mp4`（30s，约 15MB）
- 原始录屏：`source/raw_1307.mp4`

## 粗剪：去掉了什么
| 原片 | 内容 | 处理 |
|---|---|---|
| 0–1.0s、43.7s 以后 | OBS 窗口 | 剪掉 |
| 全程顶部 0–70px | 浏览器标签栏、地址栏 | 裁掉（裁成 1102×620 的 16:9 区域） |
| 全程底部 | 浏览器状态栏（鼠标悬停链接时出现） | 裁掉 |
| 26.0–27.8s | 浏览器下载面板 | 跳过：25.75s 点击下载后直接接 28.25s |
| 7–10s、15–19s | 解析加载、文案滚动 | 2–4 倍加速 |

## 结构（每个运镜都从拍点开始）
| 时间 | 画面 | 文案 |
|---|---|---|
| 0–2 | 图形开场：手机卡片带"@水印"，抖动后被擦掉 | 刷到好视频 → 想保存却有水印？ |
| 2–4 | 标题，网站同款紫色角括号；录屏窗口从下方升起 | 免费解析【去水印】/ 一个入口 · 支持 30+ 平台 |
| 4–10 | 首页录屏：推近输入框 → 下移到平台列表（计数 0→30+，平台名环绕）→ 推近解析按钮，点击波纹 | 粘贴分享链接 / 支持 30+ 平台 / 一键解析 |
| 10–12 | 紫底图文卡，平台名滚动 | 一个入口 多个平台 30+ |
| 12–18 | 解析结果录屏：甩入 → 推近视频 → 推近文案面板 → 推近下载按钮，点击 → 下载已开始 | 解析中… / 文案一键提取 / 无水印下载 · 视频·封面·音频 / 高清原画 · 无水印 |
| 18–20 | 黑底卡片 | 无水印：视频 / 图片 / 文案 |
| 20–24 | 教程四步卡片每半拍点亮一张 → FAQ 推近"功能收费吗？"的回答 | 01–04 / 四步搞定 / 不收费 · 免注册 · 不限次数 |
| 24–28 | 卖点逐拍切换，每个一种动效（砸落、上升、翻转、拉伸、侧滑） | 免费使用 / 无需注册 / 不限次数 / 30+ 平台 / 一个入口 / 无水印下载 / 图片·视频 / 文案提取 |
| 28–30 | 结尾卡 | 免费解析去水印工具 / 一个入口，支持多个平台 / media.agentcore.top / 立即使用 → |

宣传语以网站自己的说法为准（FAQ："解析、下载和口播文案提取均免费，无需注册或登录，也不设置每日使用次数额度"）。"30+ 平台"为产品方提供的口径。

## 目录
| 路径 | 内容 |
|---|---|
| `film/promo.js` | 画面合成：录屏时间重映射（`SEGS`）、每个镜头的运镜关键帧（`CAM_*`）、图文卡片 |
| `film/score.py` | 配乐：120 BPM 明快电子，Am–F–C–G；运镜嗖声、气泡"啵"声、鼠标点击声 |
| `film/render.mjs` | 渲染（4 页并行，16 子帧运动模糊） |
| `fonts.sh` | 改文案后重新下载思源黑体子集 |
