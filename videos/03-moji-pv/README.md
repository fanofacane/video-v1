# 03 · 文字PV

第三期成片：30 秒竖屏（1080×1920）原创日系"文字PV"（歌词动态视频），150 BPM。参考了一段文字PV教程录屏的视觉风格：红 / 黑 / 白 + 暗青绿裂纹，细明朝体竖排歌词逐字弹出，像素心、文字墙、马赛克故障、胶片条、黑框大字。歌词、画面、音乐全部原创，每个字出现时都"唱"一个元音。

- 成片：`output/moji_pv.mp4`（30s，1080×1920，30fps，约 20MB）
- 提示词：仓库根目录 `PROMPT_文字PV.md`

## 分镜
| 时间 | 歌词 | 画面 | 声音 |
|---|---|---|---|
| 0–3.2 | ねえ / 聞こえてる？ | 暗青绿裂纹底，红色菱形框，带暂停符号的像素心 | 钢琴琶音前奏 |
| 3.2–6.4 | 何回目の / 嘘だろう | 白纸，粗黑横条逐拍砸入，虚线圆，红色描边 ？ 阵列 | 主歌 |
| 6.4–9.6 | 愛してる | 黑底"愛してる"文字墙 + 红色锯齿像素心，字散落在心上，画面倾斜 | 副歌前 |
| 9.6–11.2 | なんて / 言わないで | 灰度马赛克每八分音符跳一次，红描边黑心，白色乱线，便签纸 | **故障抽空** |
| 11.2–12.8 | I LOVE YOU → HATE | 青绿底黑块，箭头飞入，红色斜划，LOVE/HATE 逐帧闪切 | 蓄力，12.6 静音 |
| 12.8–16.0 | 何十回 / 何百回 | 黑底红色胶片条 + 细交叉线，老虎机式滚动的红色 9 | **Drop** |
| 16.0–19.2 | 壊れた / 心臓 | 红色噪点底，黑框巨字定格砸落，黑条斜劈，镜像万花筒转场 | Drop |
| 19.2–22.4 | それでも | 像素心从下往上逐块碎落 | **骤降**：半速 |
| 22.4–25.6 | 好きだった | 青绿底红六边形，暂停 → 播放，黑块里的「好」闪成「嘘」 | 最终 Drop |
| 25.6–28.8 | さよなら | 马赛克 → 白纸，字最后碎成像素飘散 | 渐弱 |
| 28.8–30 | — | 黑底小像素心，"文字PV / STUDY Nº03" | 最后一击 |

## 目录
| 路径 | 内容 |
|---|---|
| `film/lyrics.js` | 歌词与时间表（画面和音乐共用） |
| `film/pv.js` | 全部画面（Canvas 2D，每帧是时间 t 的纯函数），纹理在启动时程序化生成 |
| `film/score.py` | 配乐：钢琴琶音、摇滚鼓、贝斯、超级锯齿、共振峰人声（每个字一个元音） |
| `film/render.mjs` | 竖屏渲染，4 页并行，每帧 16 子帧运动模糊 |
| `film/fonts/` | Shippori Mincho 子集（仅含用到的字）+ Montserrat 900 |
| `fonts.sh` | 改歌词后重新下载字体子集 |

## 构建
```bash
./build.sh
```
