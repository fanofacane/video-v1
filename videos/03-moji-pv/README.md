# 03 · 文字PV

第三期成片：30 秒横屏（1920×1080）原创日系"文字PV"（歌词动态视频），150 BPM。参考了一段文字PV教程录屏的视觉风格：红 / 黑 / 白 + 暗青绿裂纹，细明朝体歌词逐字弹出（横排、散排为主），像素心、文字墙、马赛克故障、胶片条、黑框大字。歌词、画面、音乐全部原创，每个字出现时都"唱"一个元音。

- 成片：`output/moji_pv.mp4`（30s，1920×1080，30fps，约 20MB）
- 提示词：仓库根目录 `PROMPT_文字PV.md`

## 目录
| 路径 | 内容 |
|---|---|
| `film/lyrics.js` | 歌词与时间表（画面和音乐共用） |
| `film/pv.js` | 全部画面（Canvas 2D，每帧是时间 t 的纯函数），纹理在启动时程序化生成 |
| `film/score.py` | 配乐：钢琴琶音、摇滚鼓、贝斯、超级锯齿、共振峰人声（每个字一个元音） |
| `film/render.mjs` | 横屏渲染，4 页并行，每帧 16 子帧运动模糊 |
| `film/fonts/` | Shippori Mincho 子集（仅含用到的字）+ Montserrat 900 |
| `fonts.sh` | 改歌词后重新下载字体子集 |

## 构建
```bash
./build.sh
```
