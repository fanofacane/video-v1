# 02 · COLOR CLASH

第二期成片：30 秒原创波普风文字卡点动画《COLOR CLASH》（150 BPM，高饱和撞色）。每一段一组撞色，颜色踩着拍子硬切；音乐有完整的起伏：律动 → 抽空 → 蓄力 → 静音 → Drop → 磁带急停 + 静音 → Drop 2 → 收尾。

- 成片：`output/color_clash.mp4`（30s，1920×1080，30fps，约 18MB）
- 提示词：仓库根目录 `PROMPT_COLOR_CLASH.md`

## 节奏与能量
| 时间 | 段落 | 画面 | 声音能量 |
|---|---|---|---|
| 0–3.2 | TURN IT UP | 粉底；UP 两帧定格砸落；第二小节每拍换底色 粉→橙→青→紫→黄 | 开场即进鼓，滤波打开 |
| 3.2–6.4 | COLOR vs CLASH | 黄/蓝斜切分屏，两词对撞，VS 贴纸；每拍黄蓝互换 | 律动 |
| 6.4–9.6 | RED HOT | 红底四行跑马灯，HOT 锯齿贴纸弹出、旋转，放大铺满画面 | 律动 + 主旋律 |
| 9.6–11.2 | 抽空 | 黄底小字 WAIT FOR IT，节拍器 | **骤降**：无底鼓无贝斯 |
| 11.2–12.6 | 蓄力 | LOUDER 变大，底色 4 分 → 8 分 → 16 分音符闪烁 | 军鼓滚奏 + 上升音 |
| 12.6–12.8 | 静音 | 纯黑 | **静音** |
| 12.8–19.2 | DROP | BOOM（定格砸落、冲击波）→ BOUNCE（逐字弹跳）→ CLAP!（2/4 拍重击）→ SHAKE（RGB 抖动） | 最高 |
| 19.2–20.0 | STOP | STOP 定格砸落后被压扁 | **磁带急停**，然后静音 |
| 20.0–20.8 | ONE MORE TIME | 三个词按八分音符叠出，冲向镜头 + 白闪 | 三连重音 |
| 20.8–27.2 | DROP 2 | 彩虹斜条纹 LOUDER → 四宫格 FEEL IT IN COLOR → 每拍一色 PINK LIME BLUE GOLD → 彩条 ALL AT ONCE | 比第一次更满 |
| 27.2–30 | 收尾 | COLOR CLASH 标题卡 + Nº02 贴纸，28.8 最后一击 + 彩纸爆开 | 最后一击后余音 |

## 目录
| 路径 | 内容 |
|---|---|
| `film/clash.js` | 全部动效（Canvas 2D，每帧是时间 t 的纯函数）；硬切用整帧对齐的时间，避免运动模糊把两种颜色混在一起 |
| `film/score.py` | 配乐与音效（numpy 合成），包括共振峰"人声切片"、磁带急停、静音段 |
| `film/render.mjs` | Playwright 渲染：4 页并行，每帧 16 个子帧在页面内平均（180° 快门） |
| `film/index.html` | 画布页面；直接用浏览器打开可实时预览（无声） |
