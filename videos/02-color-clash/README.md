# 02 · COLOR CLASH

第二期成片：30 秒原创波普文字卡点动画《COLOR CLASH》（150 BPM）。
**固定四色**：粉 `#FF2E88`、蓝 `#2B2BFF`、黄 `#FFE500`、墨 `#14101F`，全片不出现第五种颜色。每一段一个专属特效；音乐有完整起伏：律动 → 抽空 → 蓄力 → 静音 → Drop → 磁带急停 + 静音 → Drop 2 → 收尾。

- 成片：`output/color_clash.mp4`（30s，1920×1080，30fps，约 21MB）
- 提示词：仓库根目录 `PROMPT_COLOR_CLASH.md`

## 段落、特效与能量
| 时间 | 段落 | 专属特效 | 声音能量 |
|---|---|---|---|
| 0–3.2 | TURN IT UP | 切片拼合入场；UP 立体挤出字，每拍光源方向转 90°，底色蓝/粉/黄硬切 | 开场即进鼓 |
| 3.2–6.4 | COLOR vs CLASH | 斜分界线两侧颜色互换，字跨过分界线自动反色；分界线每拍转 45°，反色扫过字母 | 律动 |
| 6.4–9.6 | HOT | 环形文字隧道无限推进；HOT 锯齿贴纸弹出、自转，放大铺满 | 律动 + 主旋律 |
| 9.6–11.2 | 抽空 | 黄底小字 WAIT FOR IT + 节拍器，大量留白 | **骤降** |
| 11.2–12.6 | 蓄力 | 网点组成的 LOUDER，网点由小变实；底色 4 分→8 分→16 分音符闪烁 | 滚奏 + 上升音 |
| 12.6–12.8 | 静音 | 墨色黑场 | **静音** |
| 12.8–14.4 | BOOM | 定格砸落，之后每拍字被横切成 9 条错位抖动 + 冲击波 | 最高 |
| 14.4–16.0 | BOUNCE | 橡皮字：上升拉长、落地压扁，粉色描边残影 | 最高 |
| 16.0–17.6 | CLAP | 两块黄色面板像双手一样上下合拢，打开时 CLAP! 砸出 | 最高 |
| 17.6–19.2 | SHAKE | 故障切片：每 1/16 拍字母横条随机错位，粉/蓝重影 | 最高 |
| 19.2–20.0 | STOP | 定格砸落后随磁带急停被压扁 | **急停 + 静音** |
| 20.0–20.8 | ONE MORE TIME | 翻牌（split-flap）逐词翻出，冲向镜头 + 黄闪 | 三连重音 |
| 20.8–22.4 | LOUDER | 文字滚筒：多行 LOUDER 包在圆筒上，每拍滚一行 | 比第一次更满 |
| 22.4–24.0 | FEEL IT IN COLOR | 四张卡片逐拍翻面，最后顺时针换位 | Drop 2 |
| 24.0–25.6 | PINK / BLUE / GOLD / CLASH! | 每拍新颜色从中心圆形扩散（虹膜转场）；CLASH! 三条色带上下插入，字在每条里换色 | Drop 2 |
| 25.6–27.2 | ALL AT ONCE | 三色竖条纹波动，字在每条纹里显示成另一种颜色 | Drop 2 |
| 27.2–30 | 标题卡 | COLOR CLASH 立体挤出字（呼应开头），28.8 最后一击 + 三色彩纸 | 余音 |

## 目录
| 路径 | 内容 |
|---|---|
| `film/clash.js` | 全部动效（Canvas 2D，每帧是时间 t 的纯函数）；四色常量在文件顶部。硬切用整帧对齐的时间，避免运动模糊把两种颜色混在一起 |
| `film/score.py` | 配乐与音效（numpy 合成），包括共振峰"人声切片"、磁带急停、静音段 |
| `film/render.mjs` | Playwright 渲染：4 页并行，每帧 16 个子帧在页面内平均（180° 快门） |
| `film/index.html` | 画布页面；直接用浏览器打开可实时预览（无声） |
